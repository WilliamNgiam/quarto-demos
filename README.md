# Quarto Live Starter for GitHub Pages & Canvas LMS

Interactive demos in [Quarto](https://quarto.org/) starter project using [`r-wasm/quarto-live`](https://r-wasm.github.io/quarto-live/) to run interactive Python (`Pyodide`) and R (`webR`) code cells client-side via WebAssembly—hosted statically on **GitHub Pages** and embeddable inside **Canvas LMS** via `<iframe>`.
