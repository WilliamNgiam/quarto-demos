# Quarto Live Exercises and Lessons

Interactive lessons in [Quarto](https://quarto.org/) using [`r-wasm/quarto-live`](https://r-wasm.github.io/quarto-live/) to run interactive Python (`Pyodide`) and R (`webR`) code cells client-side via WebAssembly—hosted statically on **GitHub Pages** and embeddable inside **Canvas LMS** via `<iframe>`.
